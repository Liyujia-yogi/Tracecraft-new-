# TRACECRAFT 项目摘要

## 一句话定位

TRACECRAFT（知构）是一套面向产品与设计团队的需求解析与设计评审平台，把原始需求、结构化分析、设计稿、评审意见、人工处置和 Skill 优化连接为可追溯证据链。

## 项目类型与成熟度

- 类型：AI 辅助的产品设计协作与体验治理平台
- 形态：Vue 3 + TypeScript + Element Plus 前端，Express 本地服务端
- 成熟度：可运行并留有真实记录的本地全栈 MVP
- 非证据范围：尚无正式生产部署、组织级用户规模、效率对照、满意度或商业指标

## 核心用户

- 产品经理：上传、编辑需求，处理待确认项
- UI/UX 设计师：消费解析结果，上传设计稿，处理评审意见
- 设计评审者：核对需求证据、风险、影响和建议
- 平台管理员：配置模型，查看全部记录，生成候选 Skill 优化报告

## 核心闭环

原始需求 → 结构化解析 → 待确认项与版本 → 设计稿版本 → 设计评审 → 意见处置 → 不可变快照 → 反馈驱动的候选 Skill 优化

## 关键体验创新

1. Rxxx 原文编号、页面、流程和评审意见之间可追溯。
2. 待确认项可回答、忽略、恢复，并驱动新解析版本。
3. 已解析需求与未解析原文分别采用适配的评审路径。
4. 评审问题可回到设计页面，以标注点定位。
5. 部分失败保留成功结果，只重试失败页面。
6. 保存后的评审成为不可修改快照。
7. 反馈只生成候选优化，不直接修改生产 Skill。
